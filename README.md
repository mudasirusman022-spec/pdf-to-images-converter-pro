# PDF to Images Converter

A simple web tool built with Python and Flask that converts PDF files into images.

## Features
- Upload PDF files
- Convert each page into an image
- Preview and download images
- Download all images as ZIP

## Tech Stack
- Python
- Flask
- HTML, CSS
- pdf2image

## How to Run
1. Install dependencies  
   pip install -r requirements.txt
2. Run the app  
   python app.py
3. Open browser  
   http://127.0.0.1:5000
